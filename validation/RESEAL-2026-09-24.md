## Why a surgical refresh and not a re-run

These records were produced on the original author machine; their recorded `argv` and
input paths point at macOS work trees, e.g.

```text
/Users/wgs/Documents/Codex/2026-09-17/zhi/work/gtsim-ada-alignment-20260921-r1/repo/build/ada-e2e-r2/ada_cache_replay
```

Those work trees are not present on this host, so the same experiments **cannot** be
re-executed here. Re-running on Linux would have replaced the measured CPU/wall values
and the recorded `argv` with different ones, turning these records into different
experiments rather than re-sealing them.

Only one file's content changed, so only that file's hash was updated.
