# GTSim v0.1.0 validation

v0.1.0 validates the supplied H100 GEMM and FA3 reference builders using
the measurement points in `validation/data/`.

| Workload | Cases | MAPE | Pearson r |
| --- | ---: | ---: | ---: |
| H100 GEMM | 8 | 2.65% | 0.999758 |
| H100 FA3 | 6 | 9.79% | 0.999679 |

Reproduce the report with:

```bash
python3 scripts/run_validation.py --build-dir build
```

The command writes per-case results to `validation/results/`.
